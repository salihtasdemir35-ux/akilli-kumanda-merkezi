# platform/network

MVP'de Wi-Fi/yerel ağ entegrasyonu yoktur; INTERNET izni istenmez.
Sonraki aşama: yalnızca belgelenmiş yerel protokoller (ör. üreticinin yayımladığı yerel API'ler,
mDNS/NSD ile ilan edilen servisler) ve kullanıcının açıkça eklediği cihazlar. Genel ağ taraması yapılmayacak.
Hedef SDK yükseltilirken Android'in yerel ağ erişimi izin gereksinimleri yeniden kontrol edilecek.
